  • Baseline selection: previous non-draft, non-prerelease release with the same langchain-core== prefix (langchain-core==1.6.1). Releases tagged a1..a4 are alphas with prerelease=false on GitHub but were not in this prefix anyway.
  • Commit vs PR data: file lists come from PR file lists (all 48 commits map 1:1 to a PR); PR additions/deletions matched the per-file sums for all 48 PRs.
